# LTspice検証：隣接行の切替

入力：写真を基に再定義したP-MOS行アノード駆動回路。

出力：LTspiceで編集・実行できる `row_handoff.asc`、同一構成の `row_handoff.cir`、実行ログ `row_handoff.log`、測定表 `results.csv` / `results.json`。

## 開く・再実行

1. LTspiceで `row_handoff.asc` を開く。
2. Run（三角ボタン）を押す。4条件の過渡解析を実行する。
3. 波形で `I(VSENSE0)`、`I(VSENSE1)`、`V(GATE0)`、`V(GATE1)`、`V(BLANK)` を確認する。`VSENSE0/1`は行電流測定用の0V電圧源。
4. View → SPICE Error Log で `.meas` 結果を見る。エラーログという名前でも正常時の測定値が記録される。
5. プロジェクト直下で `node simulation/ltspice/verify.cjs` を実行すると測定値を表に変換する。

`run.ps1` はバッチ実行用。LTspiceが正常終了しログが揃っていない場合はエラーを返す。GUIからの実行でも同じ検証が可能。解析結果のrawは再生成できるためGit対象外。

## 回路の意味と仮定

隣接する旧行・新行の2行を取り出し、赤48列、緑48列を同時点灯する最大負荷を試す。同色48個のLEDはSPICEのダイオードarea=48で集約し、定電流負荷は各色48×15.27mA。これは同一モデルの48並列と等価だが、個別LEDのばらつきや個別画素データを再現しない。

|構成|モデル・設定|
|---|---|
|外部電源|理想5V + 配線抵抗0.1Ω|
|バルクコンデンサ|1000µF、ESR 0.05Ω|
|74HC595の出力|PWL電圧源CTL0/1。シリアル動作・IC伝搬遅延は未再現|
|ULN2803A|スイッチRon=20Ω、出力Low=0.8Vの仮定等価モデル。蓄積時間は未再現|
|P-MOS|明示的なVDMOS仮定モデルPMOS_ASSUMED。AO3401A等のメーカー提供モデルではない|
|ゲート周辺|直列100Ω、G-S間10kΩ、追加容量1nF / 4nF。内蔵Cgs=1nF等を別途モデルに含む|
|TLC5928出力|BLANKに連動した行動電流源。出力電圧0.4V未満で線形に電流低下する仮定。IC内部モデルではない|
|赤/緑LED|Is・N・Rs・Cjoを定めた仮定ダイオード。LT-5016M1実測モデルではない|
|1MΩアノード抵抗|浮遊ノードの安定化用。実機の追加部品として確定したものではない|

各端子の同名フラグが電気的に接続される。図面はLTspice標準の電源・抵抗・容量・PMOS・スイッチ・ダイオード・行動電流源シンボルのみを使用する。

初期は行0選択・BLANK=H、125µsで点灯。1msで行0をOFF、行1をONに指示し、同時にBLANKをHへ戻す。10µsまたは100µs後にBLANKをLへ戻す。行切替前の112bit転送はこの電気試験では省略し、更新後の行出力を直接刺激する。

## 実行結果

LTspice 26.1.1 for Windowsで `row_handoff.asc` を実際に読み込み、Runで過渡解析した。4条件ともGmin steppingで動作点が収束し、解析・測定が完了した。ログは同梱。

|消灯待ち|追加ゲート容量|旧行電流ピーク*|判定|
|---:|---:|---:|---|
|10µs|1nF|689.801mA|FAIL|
|100µs|1nF|0.164mA|PASS|
|10µs|4nF|719.033mA|FAIL|
|100µs|4nF|0.055mA|PASS|

*BLANK解除後2µsから1.4msまでの旧行・両色合計電流の最大。解除直後2µsの過渡電流は判定対象外。数値の小さい電流にはモデル容量の変位電流が含まれるため、そのまま発光量を表さない。

4条件共通で、定常の合計点灯電流は約1.466A、新行電流も約1.466A。電源最低値は約4.854V。BLANK中電流は数値誤差の範囲でほぼゼロ。ただしBLANK源そのものが理想動作なので、これはTLC5928実部品の漏れ電流を検証した結果ではない。

仮の合格条件は定常電流誤差±2%、BLANK中電流1mA未満、旧行電流1mA未満、電源4.5V以上。部品仕様で定められた閾値ではなく、このテストの設計要件。

**設計への反映：10µsの待ちは棄却し、100µsを暫定採用した。** 主回路図とVCDも変更済み。行周期を1msに保ち、点灯時間を875µsから785µsへ短縮。フレームは62.5Hz、画素実効Dutyは4.91%、平均電流は約0.749mAとなる。

この100µsはこの仮定モデルと4条件での結果。実部品のばらつき、温度、ULNの蓄積時間、電源投入、異常状態を網羅していない。AO3401A等の実モデル、LED特性、配線・基板条件を確定して再解析するまで、実機合格とは判定しない。

赤48経路のシンク出力段損失はモデル上約2.054W、TLC3個に均等に割り当てれば点灯中約0.685W/IC。これは接合温度の解析ではない。全16行点灯時は同じTLCが毎行働くため、IC損失に1/16を掛けない。

## 再生成

`node simulation/ltspice/build.cjs` はASCとCIRを共通部品表から作る。回路を変更する際はこのソースを変更するか、GUI編集版を別名保存して維持する。再生成するとASC手編集は上書きされる。

`verify.cjs` はログから4条件の全測定を取得する。FAIL条件も結果に残す。解析が未完了・測定が欠けている場合に計算値で補填しない。
